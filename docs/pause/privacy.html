퍼즈 개인정보 처리방침

수집 정보, 저장 위치, 권한 사용 목적을 안내합니다.

시행일: 2026년 9월 3일

퍼즈는 사용자가 직접 고른 앱 앞에 잠깐의 시간을 만들어주는 앱입니다. 현재 버전은 계정, 광고, 분석 SDK, 외부 서버 전송 없이 기기 안에서 동작하도록 설계되어 있습니다.

1. 개인정보 처리 원칙

퍼즈는 현재 버전에서 이름, 이메일, 전화번호, 연락처, 위치, 사진, 결제 정보 같은 개인정보를 직접 수집하지 않습니다. 회원가입과 로그인도 제공하지 않습니다.

앱 기능을 위해 필요한 설정값은 사용자의 기기 내부 저장소에 저장됩니다. 외부 서버로 전송하거나 광고, 분석, 트래킹 목적으로 사용하지 않습니다.

2. 기기 안에 저장될 수 있는 정보

앱은 기능 제공을 위해 다음 정보를 기기 안에 저장할 수 있습니다.

  • 온보딩 완료 여부
  • 사용자가 선택한 앱, 카테고리, 웹 도메인에 대한 Apple Screen Time 토큰
  • 퍼즈 켜짐 여부, 퍼즈 시작 시각, 종료 예정 시각
  • 사용자가 설정한 퍼즈 시간
  • 퍼즈 종료 알림 설정 여부
  • DeviceActivity 예약 상태, 마지막 동작 시각, 오류 메시지 등 진단에 필요한 로컬 상태

3. 스크린 타임 권한 사용

퍼즈는 사용자가 직접 선택한 앱, 카테고리, 웹 도메인 앞에 퍼즈 화면을 보여주기 위해 Apple Screen Time API의 FamilyControls, ManagedSettings, DeviceActivity 기능을 사용합니다.

이 권한은 사용자가 직접 고른 항목에 잠깐의 시간을 두기 위한 목적으로만 사용됩니다. 권한을 허용하지 않으면 앱 선택과 퍼즈 적용 기능을 사용할 수 없습니다.

4. 선택한 앱 정보와 앱 사용 기록

사용자가 고른 앱, 카테고리, 웹 도메인은 Apple이 제공하는 불투명한 토큰 형태로 저장됩니다. 퍼즈는 선택 항목을 앱 이름 문자열로 저장하지 않으며, 사용자의 앱 사용 기록, 브라우징 내용, 메시지 내용, 알림 내용에 접근하지 않습니다.

앱 화면에서는 iOS가 제공하는 표시 정보를 통해 사용자가 선택한 대상을 확인할 수 있습니다. 이 정보는 외부 서버로 전송되지 않습니다.

5. 저장 위치와 보관 기간

퍼즈 상태와 선택값은 기기 내부의 App Group 저장소와 앱 내부 저장소에 보관됩니다. 사용자가 선택 대상을 삭제하거나 앱을 삭제하면 관련 데이터도 iOS 정책에 따라 삭제됩니다.

6. 알림 처리

사용자가 알림 권한을 허용한 경우, 퍼즈는 퍼즈 시간이 끝났을 때 알려주기 위한 로컬 알림을 예약할 수 있습니다. 현재 버전은 원격 푸시 서버를 사용하지 않습니다.

알림은 iOS 알림 설정, 집중 모드, 기기 상태에 따라 표시되지 않거나 지연될 수 있습니다.

7. 외부 전송, 제3자 제공, 광고 및 트래킹

현재 버전의 퍼즈는 Screen Time 데이터, 선택 앱 정보, 앱 사용 데이터, 브라우징 데이터를 외부 서버로 전송하지 않습니다. 또한 광고 SDK, 제3자 분석 SDK, 트래킹 SDK를 사용하지 않습니다.

사용자의 데이터를 판매, 공유하거나 광고 프로파일링 목적으로 사용하지 않습니다.

8. 사용자의 선택권

사용자는 앱 안에서 선택한 대상을 개별 삭제하거나 전체 삭제할 수 있습니다. 스크린 타임 권한과 알림 권한은 iOS 설정에서 언제든 변경할 수 있습니다. 앱을 삭제하면 기기 내부에 저장된 퍼즈 관련 데이터도 삭제됩니다.

9. 아동 개인정보

퍼즈는 만 14세 미만 아동을 주 대상으로 하지 않으며, 법정대리인의 동의 없이 아동의 개인정보를 수집하지 않습니다.

10. 변경 사항

개인정보 처리방침이 변경되는 경우 앱 또는 본 페이지를 통해 안내할 수 있습니다. Supabase, OpenAI API, 광고, 분석 SDK, 계정 기능 등 외부 전송이 포함되는 기능이 추가되면 본 방침을 업데이트합니다.
