퍼즈 서비스 이용약관

서비스 이용 조건과 책임 범위를 안내합니다.

시행일: 2026년 9월 3일

이 약관은 퍼즈 앱의 이용 조건과 사용자 및 운영자 간 권리, 의무, 책임 범위를 안내합니다.

1. 목적

이 약관은 퍼즈 앱의 이용 조건, 서비스 내용, 사용자 책임, 서비스 한계, 개인정보 및 권한 처리와 관련된 기본 사항을 정합니다.

2. 서비스 내용

퍼즈는 사용자가 직접 선택한 앱, 카테고리, 웹 도메인 앞에 퍼즈 화면을 표시하여 짧은 시간을 두고 다시 선택할 수 있도록 돕는 앱입니다.

  • 스크린 타임 권한 연결
  • 퍼즈할 앱, 카테고리, 웹 도메인 선택
  • 퍼즈 시간 설정
  • 선택 대상 앞에 Shield 화면 표시
  • 퍼즈 종료 알림

3. 사용자 책임

사용자는 본인의 기기와 본인이 관리할 권한이 있는 설정 범위 안에서 앱을 사용해야 합니다. 다른 사람의 기기에 권한 없이 앱을 설치하거나 설정해서는 안 됩니다.

퍼즈 시간, 선택 대상, 알림 여부는 사용자가 직접 확인하고 관리해야 합니다.

4. 서비스의 한계

퍼즈는 사용자의 앱 사용을 영구적으로 차단하거나 특정 행동을 완전히 방지하는 앱이 아닙니다. iOS Screen Time API, 기기 상태, 권한 상태, 운영체제 정책에 따라 퍼즈 화면 표시나 자동 정리 동작이 제한될 수 있습니다.

사용자는 퍼즈 화면에서 제공되는 선택지를 통해 계속 퍼즈하거나 필요한 경우 직접 열 수 있습니다.

5. 권한

앱의 핵심 기능은 Apple Screen Time 권한이 있어야 동작합니다. 사용자가 권한을 거부하거나 iOS 설정에서 권한을 해제하면 앱 선택, Shield 적용, DeviceActivity 기반 정리 기능이 제한될 수 있습니다.

6. 데이터 저장

앱 설정, 선택한 대상 토큰, 퍼즈 상태, 퍼즈 시간, 알림 설정은 기기 내부에 저장됩니다. 현재 버전은 계정 생성, 서버 동기화, 광고, 분석, 트래킹 기능을 제공하지 않습니다.

7. 알림

퍼즈 종료 알림은 사용자가 iOS 알림 권한을 허용한 경우에만 동작합니다. iOS 알림 설정, 집중 모드, 배터리 상태, 기기 상태에 따라 알림이 표시되지 않거나 지연될 수 있습니다. 앱은 알림 도착을 보장하지 않습니다.

8. 건강, 의료, 상담 관련 고지

퍼즈는 의료, 심리 상담, 진단, 치료, 중독 치료 서비스를 제공하지 않습니다. 앱은 사용자가 직접 고른 앱 앞에 짧은 시간을 두는 보조 도구입니다.

9. 금지 행위

사용자는 다음 행위를 해서는 안 됩니다.

  • 타인의 기기나 계정에 권한 없이 앱을 설치하거나 설정하는 행위
  • 앱의 정상 동작을 방해하거나 우회 목적으로 악용하는 행위
  • 법령, 공공질서, 선량한 풍속에 반하는 목적으로 사용하는 행위

10. 책임 제한

운영자는 안정적인 서비스 제공을 위해 노력하지만, iOS 정책 변경, 권한 상태, 기기 오류, 알림 미수신, 사용자의 설정 오류 등으로 발생하는 문제에 대해 법령상 허용되는 범위 내에서 책임을 제한합니다.

11. 약관 변경

약관 변경 시 앱 또는 본 페이지를 통해 안내할 수 있습니다.
