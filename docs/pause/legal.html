퍼즈 법적 고지

퍼즈 기능의 한계와 중요한 고지를 안내합니다.

시행일: 2026년 9월 3일

퍼즈는 앱 사용을 완전히 막는 보안 도구가 아니라, 사용자가 직접 고른 앱 앞에 잠깐의 시간을 만드는 보조 도구입니다.

핵심 고지

퍼즈는 개인 디지털 웰빙 앱입니다. 사용자가 선택한 앱 앞에 퍼즈 화면을 보여주고, 시간이 지난 뒤 다시 선택할 수 있도록 돕습니다.

차단 보장 아님

앱은 특정 앱 사용을 영구적으로 차단하거나 사용자의 행동 변화를 보장하지 않습니다. iOS Screen Time API와 사용자의 권한 설정 범위 안에서 동작하며, 운영체제 정책이나 기기 상태에 따라 일부 동작이 제한될 수 있습니다.

사용자 선택

사용자는 퍼즈할 앱과 퍼즈 시간을 직접 선택합니다. 퍼즈 화면에서도 계속 기다리거나 필요한 경우 직접 열 수 있습니다. 앱은 사용자의 최종 선택을 대신하지 않습니다.

의료, 상담, 진단 목적 아님

퍼즈는 의료, 심리 상담, 진단, 치료, 중독 치료 목적의 앱이 아닙니다. 감정 상태를 진단하거나 회복을 보장하지 않습니다.

알림 고지

퍼즈 종료 알림은 로컬 알림으로 제공됩니다. iOS 알림 설정, 집중 모드, 기기 상태에 따라 표시되지 않거나 지연될 수 있으며, 앱은 알림 도착을 보장하지 않습니다.

개인정보 고지

현재 버전은 계정, 광고, 분석 SDK, 서버 동기화를 사용하지 않습니다. 선택한 앱과 퍼즈 상태는 기기 내부에 저장되며 외부 서버로 전송되지 않습니다.

향후 기능 변경

Supabase, OpenAI API, 광고, 분석 SDK, 계정, 구독 또는 부모님 기능이 추가되는 경우 개인정보 처리방침, 이용약관, App Store 개인정보 답변을 업데이트해야 합니다.
