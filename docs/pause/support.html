자주 묻는 질문

퍼즈는 어떤 앱인가요?

퍼즈는 게임, 쇼핑, SNS처럼 바로 열기 쉬운 앱 앞에서 잠깐 멈출 시간을 만들어주는 앱입니다. 앱을 완전히 막는 것보다, 사용자가 다시 고를 수 있는 작은 간격을 만드는 데 초점을 둡니다.

왜 스크린 타임 권한이 필요한가요?

선택한 앱 앞에 퍼즈 화면을 보여주려면 iOS의 Screen Time API 권한이 필요합니다. 권한을 허용하지 않으면 앱 선택과 퍼즈 적용 기능을 사용할 수 없습니다.

선택한 앱 이름이나 사용 기록이 서버로 전송되나요?

아니요. 현재 버전은 서버 전송을 사용하지 않습니다. 선택 항목은 Apple Screen Time 토큰으로 기기 안에 저장되며, 앱 사용 기록이나 브라우징 내용은 수집하지 않습니다.

퍼즈 시간이 끝나면 어떻게 되나요?

퍼즈 시간이 끝나면 앱은 로컬 상태를 정리하고, 사용자가 알림을 켠 경우 기기에서 로컬 알림을 보여줄 수 있습니다. 알림은 iOS 설정이나 집중 모드에 따라 표시되지 않을 수 있습니다.

선택한 앱을 바꾸거나 삭제할 수 있나요?

네. 앱 안에서 선택한 대상을 볼 수 있고, 개별 삭제 또는 전체 삭제가 가능합니다.
