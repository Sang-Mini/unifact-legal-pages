# 황금연휴 찾기 법적 문서

앱인토스 미니앱 `황금연휴 찾기` 심사 및 고객 안내를 위한 정적 문서입니다.

## 파일

- `index.html`: 법적 문서 홈
- `privacy.html`: 개인정보 처리방침
- `support.html`: 고객지원
- `terms.html`: 서비스 이용약관
- `legal.html`: 법적 고지

## GitHub Pages 설정

GitHub 저장소에서 아래처럼 설정합니다.

1. `Settings`
2. `Pages`
3. `Build and deployment` → `Deploy from a branch`
4. Branch: `main`
5. Folder: `/docs`
6. Save

배포 후 URL 형식은 아래와 같습니다.

```text
https://<github-id>.github.io/<repo-name>/
https://<github-id>.github.io/<repo-name>/privacy.html
https://<github-id>.github.io/<repo-name>/support.html
https://<github-id>.github.io/<repo-name>/terms.html
https://<github-id>.github.io/<repo-name>/legal.html
```
