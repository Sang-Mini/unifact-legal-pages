버스 정보가 다르게 보여요

정류장 이름과 번호, 노선 번호, 확인한 시각, 앱 버전을 알려주세요. 실제 전광판과 외부 API의 갱신 시각은 다를 수 있어요.

알림이 오지 않아요

iPhone 설정에서 버스탑잇의 위치·알림·동작 권한과 라이브 액티비티 허용 상태를 확인해 주세요. 집중 모드·절전·위치 정확도 저하·앱 강제 종료는 동작을 제한할 수 있어요. 자동감지와 라이브 액티비티 권한은 별개예요.

탑승 중 앱을 닫았어요

진행 중인 탑승은 다시 앱을 열면 복원해요. 하지만 강제 종료된 동안의 GPS 갱신과 하차 알림은 보장하지 않아요. 라이브 액티비티가 남아 있어도 계속 추적되고 있다는 뜻은 아니에요.

진단 기록이 필요한가요

필수가 아니에요. 문제 재현을 위해 직접 동의하고 기록한 경우에만 설정에서 파일을 선택해 공유할 수 있어요. 위치·이동 기록이 포함되므로 공개 게시판에 올리지 마세요. 개인정보 삭제 요청도 같은 이메일로 보내주세요.
