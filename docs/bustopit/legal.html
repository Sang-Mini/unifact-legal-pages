버스탑잇은 이동 보조 도구예요.

하차 준비와 실제 하차는 달라요

알림은 목적지 1정류장 전부터 준비를 돕는 안내예요. 실제 정류장 표지와 버스 안내방송을 함께 확인해 주세요.

실시간 정보도 지연될 수 있어요

외부 API 누락, GPS 오차, 권한·기기 상태에 따라 버스 위치와 남은 정류장 수가 틀리거나 확인 중으로 표시될 수 있어요. 안내 정확도와 알림 도착을 모든 상황에서 보장하지 않아요.

데이터 출처

국토교통부 TAGO·경기도 GBIS 공공데이터 API, Apple MapKit을 이용해요. 버스탑잇은 교통기관의 공식 앱이 아니에요. 각 제공처의 이용조건과 개인정보 정책이 적용돼요.
