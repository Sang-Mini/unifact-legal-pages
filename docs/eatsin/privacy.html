2. 어떤 정보를 사용하나요?

  • 기기 저장: 재료 이름·수량·단위·보관 위치·소비기한, 장보기 목록, 추천받거나 저장한 요리, 조리 진행 상태와 설정. 재료 관리와 조리 안내, 알림에 사용해요.
  • 추천 요청: 재료 이름·수량·단위와 우선 사용할 재료. 추가 추천에서는 중복을 줄이기 위해 앞서 받은 메뉴 제목도 보내요. 재고 식별번호·보관 위치·소비기한·사진은 추천 요청에 포함하지 않아요.
  • 서비스 보호: 접속 IP를 처리해 변환한 식별값, 호출 횟수와 만료 시각으로 과도한 요청을 제한해요. 서버 프로그램 로그에는 요청 식별자·결과 코드·처리 시간이 남아요.
  • 문의: 이메일 주소와 보내주신 내용을 문제 해결과 답변에 사용해요. 문의가 해결되어 보관 목적이 끝나면 삭제하며, 분쟁 대응이나 법령에 따른 보관이 필요한 경우는 제외해요.

재료 이름이나 문의에 비밀번호·연락처·건강정보 등 불필요한 개인정보를 입력하지 말아 주세요.

3. 외부 서비스에서는 어떻게 처리하나요?

추천 요청 시 암호화된 통신으로 잇츠인 서버를 거쳐 OpenAI API에 재료 정보를 보내 메뉴를 생성해요. 서버는 Vercel에서 운영하며, 미국 등 해외 인프라에서 처리될 수 있어요. 국내에만 저장·처리되는 서비스는 아니에요.

  • Vercel Inc.: 추천 서버 운영, 접속 처리, 호출 제한 기록 보관. 호스팅 과정에서 접속·보안 기록이 처리될 수 있어요. 보관은 서비스 제공·보안·법적 의무에 필요한 기간과 계약 조건을 따르며 모든 기록에 같은 기간이 적용되는 것은 아니에요. Vercel 개인정보 안내 · privacy@vercel.com
  • OpenAI: 전송된 재료 정보와 기존 메뉴 제목으로 추천을 생성해요. 응답 저장 옵션은 꺼져 있어요. API 데이터는 기본적으로 모델 학습에 사용되지 않지만, 보안·오용 방지 로그는 원칙적으로 최대 30일 보관될 수 있고 법적 의무나 위해 방지에 필요한 경우 더 오래 보관될 수 있어요. 모델에 따라 임시 캐시가 최대 24시간 유지될 수 있어요. OpenAI 데이터 처리 안내
  • Google AdMob: 사용자가 선택한 보상형 광고를 제공하고 시청 완료 여부를 확인해요. Google의 동의 관리 절차와 개인정보 설정을 적용하며, 광고 제공·노출 확인·부정 이용 방지를 위해 IP 주소, 기기 식별자, 광고 데이터, 앱 이용 및 광고 상호작용 정보, 진단 정보가 처리될 수 있어요. Google 개인정보처리방침 · 광고 개인정보 보호 안내

잇츠인 서버 프로그램은 추천 입력·결과 원문을 별도 데이터베이스에 보관하지 않아요. 이를 외부 제공자의 로그나 캐시도 즉시 삭제된다는 뜻으로 보장하지는 않아요. 변환한 접속 식별값과 호출 제한 기록은 만료 후 다음 요청 처리 때 정리되므로 만료 즉시 삭제되지는 않을 수 있어요.

4. 사용자가 선택할 수 있어요

추천 기능을 사용하지 않으면 새 메뉴 생성 요청은 보내지 않아요. 보상형 광고를 보지 않아도 기본 추천과 재료 관리, 기존에 저장한 요리는 계속 이용할 수 있어요. 광고 개인정보 선택을 다시 확인해야 하는 지역에서는 앱 설정의 ‘광고 개인정보 설정’에서 변경할 수 있어요. 알림은 허용한 경우 기기에서 예약하며 휴대폰 설정에서 권한을 변경할 수 있어요.

재료·장보기·저장한 요리는 각 목록에서 삭제할 수 있어요. 기기 데이터는 사용자가 삭제하거나 앱을 삭제할 때 운영체제 정책에 따라 제거되며, 운영체제 백업·복원은 별도 설정의 영향을 받을 수 있어요. 회원 계정 기반 동기화나 운영자에 의한 기기 기록 복원은 제공하지 않아요.

5. 권리 행사와 보호 조치

열람·정정·삭제·처리 정지와 정보 처리 관련 요청은 문의 이메일로 보내 주세요. 본인 확인과 처리 가능 범위를 확인해 안내해요. 운영자가 보유하지 않는 기기 내 기록은 앱에서 직접 관리해야 해요. 요청 정보는 처리에 필요한 범위에서만 확인하며, 법령상 제한이 있는 경우 그 이유를 알려드려요.

서비스 연결에는 암호화 통신을 사용하고 서버 인증 정보는 앱에 넣지 않아요. 운영 자료 접근을 제한해요. 보상형 광고에는 Google AdMob SDK를 사용하며 광고 개인정보 선택이 적용돼요. 안내 페이지를 방문하면 페이지 제공자인 GitHub가 접속 정보를 처리할 수 있어요. GitHub 개인정보 안내

6. 변경 안내

정보 처리 방식이 바뀌면 이 페이지의 시행일과 내용을 갱신하고, 중요한 변경은 시행 전에 앱 또는 안내 페이지에서 알려드려요. 별도의 동의가 필요한 변경은 해당 절차를 진행해요.
